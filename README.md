# Kreving Launchpad

Create a premium, modern, mobile-first pre-launch landing website for a new street-food discovery platform called KREVING.

BRAND

Brand name: KREVING

Concept:
Kreving is a street-food discovery platform that helps people discover interesting, popular, hidden-gem and trending street-food spots around them.

The website is a pre-launch website, not the full food-ordering application.

Primary goal:

Build curiosity about Kreving

Explain what Kreving is

Encourage users to join the early-access/waitlist

Attract street-food vendors

Establish a strong, memorable brand identity

BRAND COLORS

Use this exact primary palette:

Tomato Red: #E53935

Mustard Yellow: #F4B400

White: #FFFFFF

Dark Grey: #212121

Use Tomato Red as the main brand/action color.
Use Mustard Yellow selectively for highlights, food-related accents and important visual elements.
Use White for clean backgrounds.
Use Dark Grey for text.

Do NOT make the website look like Swiggy, Zomato, Uber Eats or other existing food-delivery platforms.

Kreving should feel like a street-food discovery/social discovery brand, not a food-delivery website.

DESIGN DIRECTION

Create a visually attractive startup landing page with:

Premium modern UI

Strong typography

Large food photography

Rounded cards

Subtle shadows

Smooth animations

Clean spacing

Modern mobile-first layout

High-quality street-food visual storytelling

Minimal but memorable design

Excellent desktop and mobile responsiveness

The overall feeling should be:

"Discover something delicious that you didn't know existed."

Avoid excessive gradients.
Avoid clutter.
Avoid generic SaaS dashboard styling.
Avoid copying any existing food app.

TECHNICAL REQUIREMENTS

Tailwind CSS

GitHub → Cloudflare Pages

Make sure the project can be exported/synced to GitHub without proprietary dependencies that would prevent independent deployment.

IMPORTANT

Do NOT build:

Payment gateway

Restaurant delivery

Live order tracking

Vendor dashboard

Admin dashboard

Real-time chat

Fake user reviews

Fake vendor accounts

Fake statistics

Only build the marketing/pre-launch experience and frontend waitlist UI.

Use realistic demo food content only for visual presentation and clearly treat it as sample content.

FINAL QUALITY REQUIREMENT

Before finishing:

Check the entire website on mobile and desktop.

Fix all responsive issues.

Check buttons and navigation.

Check form validation.

Remove placeholder lorem ipsum.

Ensure there are no broken images.

Ensure consistent Kreving branding.

Ensure the design is visually distinct from Swiggy/Zomato.

Ensure the code is clean and GitHub-ready.

Ensure the project is ready to deploy on Cloudflare Pages.

The final result should feel like a real startup's launch website, not an AI-generated template.
